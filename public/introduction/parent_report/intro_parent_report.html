ចូលមើលរបាយការណ៍

Parent Report Guide

សៀវភៅណែនាំពីរបៀបពិនិត្យមើល ទាញយកជា Excel និងបោះពុម្ពសៀវភៅតាមដានការសិក្សា និងអវត្តមានប្រចាំខែជូនមាតាបិតាសិស្ស។

ទស្សនាវីដេអូណែនាំ
Part 1

ទិដ្ឋភាពទូទៅនៃរបាយការណ៍

ផ្ទាំងខាងក្រោមនេះគឺជាទម្រង់ស្តង់ដារនៃ **សៀវភៅតាមដានការសិក្សា** ដែលត្រូវបានរៀបចំ និងគណនាដោយស្វ័យប្រវត្តិ១០០% សម្រាប់សិស្សម្នាក់ៗ៖

ជ្រើសរើសខែ និងសិស្ស

តារាងពិន្ទុ និងការវាយតម្លៃ
អវត្តមានប្រចាំខែ

១. ការវាយតម្លៃស្វ័យប្រវត្តិ (Auto Calculation)

ប្រព័ន្ធធ្វើការទាញយកពិន្ទុប្រចាំខែដែលលោកអ្នកបានបញ្ចូលមកបូកសរុប រកមធ្យមភាគ ទាញយកចំណាត់ថ្នាក់ និងផ្តល់និទ្ទេស (A, B, C...) ជូនសិស្សដោយស្វ័យប្រវត្តិ។

២. គំនូសតាងការសិក្សា (Trend Chart)

តារាងនេះនឹងបង្ហាញជាខ្សែបន្ទាត់តភ្ជាប់ពីមធ្យមភាគនៃខែនីមួយៗ ជួយឱ្យលោកគ្រូអ្នកគ្រូ និងអាណាព្យាបាលងាយស្រួលមើលឃើញពីការវិវឌ្ឍ ឬការធ្លាក់ចុះនៃការសិក្សារបស់កូនៗ។

៣. តាមដានអវត្តមាន (Attendance)

ទិន្នន័យអវត្តមាន (មានច្បាប់ និងឥតច្បាប់) ត្រូវបានទាញយកពីបញ្ជីវត្តមានប្រចាំថ្ងៃ និងធ្វើការគណនារកអត្រាភាគរយនៃវត្តមានប្រចាំខែយ៉ាងសុក្រឹត្យ។

៤. មតិយោបល់ស្វ័យប្រវត្តិ (Teacher Remarks)

ផ្អែកលើនិទ្ទេសដែលសិស្សទទួលបាន ប្រព័ន្ធនឹងបង្កើតមតិយោបល់សមស្របមួយជូនសិស្សដោយស្វ័យប្រវត្តិ ដើម្បីលើកទឹកចិត្ត ឬជំរុញការខិតខំប្រឹងប្រែងបន្ថែមទៀត។
