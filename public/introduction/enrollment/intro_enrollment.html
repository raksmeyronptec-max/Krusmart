ចូលទៅកាន់ប្រព័ន្ធ

Introduction To Enrollment

សៀវភៅណែនាំងាយស្រួលយល់សម្រាប់ការគ្រប់គ្រងទិន្នន័យសិស្ស

ទស្សនាវីដេអូណែនាំ

ប្រព័ន្ធគ្រប់គ្រង និងបញ្ចូលទិន្នន័យសិស្ស (ជំនាន់ ២.០)

Part 1

ការបំពេញព័ត៌មានមូលដ្ឋាន

ដើម្បីបញ្ចូលសិស្សថ្មី លោកអ្នកត្រូវបំពេញព័ត៌មានសំខាន់ៗមួយចំនួន។ សូមកត់សម្គាល់ថា ប្រអប់ដែលមានសញ្ញាផ្កាយ (*) គឺជាព័ត៌មានចាំបាច់ដែលមិនអាចរំលងបាន៖

១. បញ្ចូលអត្តលេខ
២. បញ្ចូលថ្នាក់ទី
៣. បញ្ចូលឈ្មោះសិស្ស
  • អត្តលេខ*: ជាលេខសម្គាល់សិស្ស (Student ID)។ ឧទាហរណ៍៖ ០០១, ០០២...
  • ថ្នាក់ទី*: បញ្ចូលកម្រិតថ្នាក់ដែលសិស្សកំពុងរៀន ឧទាហរណ៍៖ ១ក។
  • ឈ្មោះសិស្ស* និង ភេទ*: វាយបញ្ចូលឈ្មោះពេញ និងជ្រើសរើសភេទ (ប្រុស/ស្រី) ពីបញ្ជីទម្លាក់ចុះ។
  • ថ្ងៃខែឆ្នាំកំណើត*: ចុចលើប្រអប់ដើម្បីជ្រើសរើសថ្ងៃខែឆ្នាំកំណើតចេញពីប្រតិទិន។
Part 2

ការកំណត់រូបថតតំណាង (Profile Photo)

ប្រព័ន្ធផ្តល់ជម្រើស ៣ យ៉ាងក្នុងការកំណត់រូបថតឱ្យសិស្ស ដែលមានទីតាំងនៅខាងឆ្វេងដៃបំផុត៖

១. ជ្រើសរូបតុក្កតាស្រាប់ៗ
២. ជ្រើសរូបផ្ទាល់ពីទូរស័ព្ទ
៣. ទាញយករូបពី URL

១. ជ្រើសរូបតុក្កតា (Avatars)

ចុចប៊ូតុងនេះ ផ្ទាំងមួយនឹងលោតឡើងបង្ហាញរូបតុក្កតាដ៏ស្រស់ស្អាតជាច្រើន (បង្កើតដោយ AI) ដើម្បីយកមកធ្វើជារូបតំណាងសិស្សបានយ៉ាងឆាប់រហ័ស។

២. ជ្រើសរូបផ្ទាល់ (Upload)

ទាញយករូបថតពីក្នុងទូរស័ព្ទ ឬកុំព្យូទ័រ។ *ទំហំមិនត្រូវលើសពី 2MB។

Part 3

ការបញ្ចូលទីតាំងភូមិសាស្ត្រឆ្លាតវៃ

នៅពេលលោកអ្នកបំពេញទីកន្លែងកំណើត ឬទីកន្លែងបច្ចុប្បន្ន លោកអ្នកមិនចាំបាច់វាយអត្ថបទវែងៗនោះទេ៖

វាយអក្សរ១-២តួ ទីនេះមុខគេ
វានឹងទម្លាក់ជម្រើសស្វ័យប្រវត្តិ

ប្រព័ន្ធទាញទិន្នន័យស្វ័យប្រវត្តិ (Autocomplete)

  • របៀបប្រើប្រាស់៖ គ្រាន់តែវាយបញ្ចូលអក្សរ ១ ឬ ២ តួ នៅត្រង់ប្រអប់ រាជធានី/ខេត្ត នោះបញ្ជីឈ្មោះខេត្តនឹងលោតទម្លាក់ចុះមក។
  • ភាពប្រទាក់ក្រឡា (Cascading): បន្ទាប់ពីជ្រើសរើស ខេត្ត រួច ប្រអប់ ស្រុក/ខណ្ឌ នឹងបង្ហាញតែឈ្មោះស្រុកណាដែលនៅក្នុងខេត្តនោះប៉ុណ្ណោះ។
Part 4 (Important)

ការនាំចូល និងទាញយកឯកសារ Excel

ដើម្បីសន្សំពេលវេលា ប្រព័ន្ធអនុញ្ញាតឱ្យលោកអ្នកបញ្ចូលសិស្សរាប់រយនាក់ក្នុងពេលតែមួយតាមរយៈឯកសារ Excel៖

១. ទាញយកគំរូសិន
២. នាំចូលឯកសារ

1 ទាញយកគំរូ Excel

ចុចលើប៊ូតុងពណ៌ខៀវខាងក្រោមគេបង្អស់ លោកអ្នកនឹងទទួលបាន File គំរូ។ សូមវាយបញ្ចូលទិន្នន័យសិស្សចូលក្នុង File នោះ រួច Save។

2 នាំចូលទិន្នន័យ (Import)

ចុចលើប៊ូតុងពណ៌ទឹកក្រូច រួចជ្រើសរើស File ដែលអ្នកបានរៀបចំ។ ប្រព័ន្ធនឹងអានទិន្នន័យ និងរក្សាទុកចូលក្នុង Database ដោយស្វ័យប្រវត្តិ។

Part 5

ការរក្សាទុក និងកែប្រែទិន្នន័យ

ចុចរក្សាទុកទិន្នន័យ

ការរក្សាទុក (Cloud Storage)

ទិន្នន័យនឹងត្រូវរក្សាទុកទៅក្នុង Cloud Database (Firebase) ដោយមានសុវត្ថិភាពខ្ពស់ ដែលអាចបើកមើលពីឧបករណ៍ណាក៏បាន។

កែប្រែទិន្នន័យ (Edit Mode)

នៅពេលអ្នកចូលកែប្រែសិស្ស ប៊ូតុងរក្សាទុកនឹងប្តូរឈ្មោះទៅជា ធ្វើបច្ចុប្បន្នភាព ដោយស្វ័យប្រវត្តិ។

Part 6

វីដេអូណែនាំការប្រើប្រាស់

ដើម្បីកាន់តែងាយយល់ និងឃើញការអនុវត្តផ្ទាល់ សូមទស្សនាវីដេអូនៅខាងក្រោមនេះ៖

រួចរាល់ហើយ!

ប្រព័ន្ធត្រូវបានរចនាឡើងដើម្បីជួយសម្រួលការងារលោកគ្រូអ្នកគ្រូក្នុងការគ្រប់គ្រងទិន្នន័យសិស្សឱ្យកាន់តែមានភាពងាយស្រួល និងរហ័ស។
