ទស្សនាវីដេអូណែនាំ

មុខងារនេះជួយឱ្យមាតាបិតាតាមដានការសិក្សាកូនបានយ៉ាងងាយស្រួល

1
Feature Overview

គ្រប់គ្រងអត្តលេខ និង QR Code សិស្ស

មុខងារនេះនឹងធ្វើការប្រមូលអត្តលេខសិស្សទាំងអស់ដែលមានក្នុងថ្នាក់របស់អ្នក ហើយបង្កើតជា QR Code ដោយស្វ័យប្រវត្តិសម្រាប់សិស្សម្នាក់ៗ។ អ្នកអាចចុចប៊ូតុងចម្លង ដើម្បីផ្ញើឱ្យមាតាបិតាតាមតេឡេក្រាម ឬចុចបោះពុម្ពជាកាតតែម្តង។

ចុចទីនេះដើម្បីបោះពុម្ពជាកាត
QR Code និងប៊ូតុងចម្លង
  • ស្វ័យប្រវត្តិកម្ម៖ ប្រព័ន្ធទាញយករូបថត ឈ្មោះ និងអត្តលេខដោយស្វ័យប្រវត្តិ មិនចាំបាច់បញ្ចូលទិន្នន័យឡើងវិញឡើយ។
  • ភាពងាយស្រួល៖ អ្នកគ្រាន់តែចុចប៊ូតុង "ចម្លង (Copy)" នោះអត្តលេខសិស្សនឹងត្រូវបានចម្លងទុក សម្រាប់ផ្ញើទៅកាន់ក្រុមតេឡេក្រាម ឬជូនអាណាព្យាបាលដោយផ្ទាល់។
2
Print Mode

ទម្រង់កាតគណនីអាណាព្យាបាល

នៅពេលលោកគ្រូអ្នកគ្រូចុចប៊ូតុង "បោះពុម្ពកាត" ប្រព័ន្ធនឹងរៀបចំសន្លឹកកាតជាទម្រង់ A4 ដោយស្វ័យប្រវត្តិ ដែលមានកាតជាច្រើនក្នុងមួយសន្លឹក ងាយស្រួលក្នុងការកាត់ចែក។

លេខកូដថ្នាក់ និងអត្តលេខសិស្ស
ស្កេនដើម្បីចូល Parent Portal

វិធីទី១៖ ស្កេនចូលដោយផ្ទាល់

អាណាព្យាបាលគ្រាន់តែយកទូរស័ព្ទដៃមកស្កេនលើ QR Code នោះវានឹងនាំពួកគាត់ចូលទៅកាន់ប្រព័ន្ធ Parent Portal របស់កូនគាត់ភ្លាមៗ ដោយមិនបាច់វាយលេខកូដអ្វីទាំងអស់។

វិធីទី២៖ វាយបញ្ចូលលេខកូដ

ប្រសិនបើពួកគាត់មិនចេះស្កេន ពួកគាត់អាចចូលទៅកាន់តំណភ្ជាប់ (Link) រួចវាយបញ្ចូលលេខកូដទាំង២ គឺ៖ "លេខកូដថ្នាក់ (Teacher UID)" និង "អត្តលេខសិស្ស (Student ID)" ដែលមានបង្ហាញនៅលើកាត។

3
Parent Access

ការចូលប្រើប្រាស់របស់មាតាបិតា

នៅពេលមាតាបិតាទទួលបានកាត ពួកគាត់អាចចូលទៅកាន់ប្រព័ន្ធ Parent Portal តាមរយៈទូរស័ព្ទដៃរបស់ពួកគាត់បានយ៉ាងងាយស្រួល ដោយការស្កេន QR Code ឬវាយបញ្ចូលលេខកូដ។

វាយលេខកូដដោយដៃ
ចុចស្កេន QR ចូលលឿន

បទពិសោធន៍ប្រើប្រាស់រលូន

ប្រព័ន្ធត្រូវបានរចនាឡើងយ៉ាងសាមញ្ញបំផុតសម្រាប់មាតាបិតា។ ការចុចប៊ូតុង "ស្កេន QR" នឹងបើកកាមេរ៉ាស្កេនកាតដែលបានបោះពុម្ព ហើយបំពេញលេខកូដដោយស្វ័យប្រវត្តិដើម្បីនាំពួកគាត់ចូលទៅមើលទិន្នន័យកូនៗបានភ្លាមៗដោយសុវត្ថិភាព។
