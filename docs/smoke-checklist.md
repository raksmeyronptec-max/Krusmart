# បញ្ជីត្រួតពិនិត្យក្រោយដំឡើង (Post-deploy smoke checklist)

ដំណើរការនេះធ្វើឡើង **បន្ទាប់ពី** migrations `00018`–`00024` ត្រូវបានអនុវត្តរួច
(មើល [`deploy-00018-00024.md`](./deploy-00018-00024.md)) និងបន្ទាប់ពីកូដកម្មវិធី
ត្រូវបានដំឡើង។

រាល់ធាតុមានបីផ្នែក៖ **ចុចអ្វី** · **គួរឃើញអ្វី** · **បើមិនដូចនោះ**។

> ធាតុសំខាន់បំផុតគឺទី ១ និងទី ២។ បើពីរនេះមិនជាប់ សូមកុំបន្តទៅមុខ —
> គណនីចាស់ជាអ្វីដែលយើងមិនអាចបំបែកបាន។

---

## ១. គ្រូចាស់ (legacy) — បញ្ជីសិស្ស និងបញ្ជីមុខវិជ្ជាមិនប្រែប្រួល

**ចុចអ្វី** ចូលគណនីគ្រូចាស់ម្នាក់ (គណនីដែលមិនទាន់មានថ្នាក់រៀនក្នុងប្រព័ន្ធថ្មី) →
បើក **បញ្ជីសិស្ស** → រួចបើក **ពិន្ទុ › បញ្ចូលពិន្ទុ**។

**គួរឃើញអ្វី**
- សិស្សគ្រប់រូបនៅដដែល ចំនួនដូចមុន
- បញ្ជីមុខវិជ្ជាមាន **១៤ ជម្រើស** ដូចមុន (ភាសាខ្មែរ គ្រប់បំណិន, គណិតវិទ្យា គ្រប់ផ្នែក, …)
- ពិន្ទុពេញនៅតែ ១០ · មធ្យមភាគចេញជា /១០

**បើមិនដូចនោះ** បើបញ្ជីសិស្សទទេ ឬបញ្ជីមុខវិជ្ជាខ្លីជាងមុន — នេះជាបញ្ហាធ្ងន់ធ្ងរ។
កុំប្រាប់គ្រូឲ្យចុចប៊ូតុងសង្គ្រោះ។ ត្រឡប់កូដកម្មវិធីទៅជំនាន់មុនសិន
រួចរាយការណ៍មកវិញ។

---

## ២. ពិន្ទុបឋមសិក្សា — លេខមិនប្រែប្រួល

**ចុចអ្វី** ជ្រើសថ្នាក់បឋមសិក្សាមួយដែលមានពិន្ទុរួចហើយ → **ពិន្ទុ › តារាងពិន្ទុសរុប** →
កត់ត្រាមធ្យមភាគ និងនិទ្ទេសរបស់សិស្ស ២–៣ នាក់ → រួចបើក **ចំណាត់ថ្នាក់**។

**គួរឃើញអ្វី**
- មធ្យមភាគ និងនិទ្ទេសដូចមុនការដំឡើងបេះបិទ
- លេខនៅ **ចំណាត់ថ្នាក់** ត្រូវគ្នានឹងលេខនៅ **តារាងពិន្ទុសរុប** សម្រាប់សិស្សតែម្នាក់
- និទ្ទេស A = ល្អណាស់ (បឋមសិក្សា)

**បើមិនដូចនោះ** បើលេខប្រែប្រួល សូមកត់ត្រាទុក៖ ឈ្មោះសិស្ស មុខវិជ្ជា ខែ
លេខចាស់ និងលេខថ្មី។ នេះជាព័ត៌មានចាំបាច់បំផុតសម្រាប់ការស៊ើបអង្កេត។

> ចំណាំ៖ របាយការណ៍អាណាព្យាបាល **ចំណាត់ថ្នាក់** អាចប្រែប្រួល ១ លេខ សម្រាប់សិស្ស
> ដែលមានពិន្ទុក្នុងមុខវិជ្ជាបន្ថែមរបស់គ្រូ។ នេះជាការកែដោយចេតនា — ដើម្បីឲ្យ
> ចំណាត់ថ្នាក់លើក្រដាស និងលើអេក្រង់ដូចគ្នា។

---

## ៣. គ្រូថ្មី — ដំណើរការចុះឈ្មោះពេញលេញ

**ចុចអ្វី** បើក `/choose-level` ក្នុង private window → ជ្រើស **បឋមសិក្សា** →
ចូលដោយ Google → បង្កើតស្ថាប័នថ្មី → ទៅដល់ទំព័រដើម → បង្កើតថ្នាក់ →
បន្ថែមសិស្ស ១ នាក់។

**គួរឃើញអ្វី**
- **អនុវិទ្យាល័យ** ស្រអាប់ និងសរសេរ «ឆាប់ៗនេះ» — ចុចមិនបាន
- **វិទ្យាល័យ** ចុចបាន និងសរសេរ «ថ្នាក់ទី១២ ប៉ុណ្ណោះ»
- ក្រោយបង្កើតស្ថាប័ន → ទៅទំព័រដើមភ្លាម (មិនមែនទៅជំហានកម្រិតសិក្សា)
- ទំព័រដើមបង្ហាញប៊ូតុង «បង្កើតថ្នាក់»
- ក្រោយបង្កើតថ្នាក់ → បន្ថែមសិស្សបាន ហើយសិស្សនោះឃើញនៅ **បញ្ជីសិស្ស**

**បើមិនដូចនោះ** បើបង្កើតថ្នាក់មិនបាន ហើយមានសារបញ្ហា — ពិនិត្យថា migration
`00018`/`00019` បានអនុវត្តរួចឬនៅ (មើលសំណួរ preflight ក្នុងឯកសារដំឡើង)។
ការបង្កើតថ្នាក់ត្រូវការ function នោះ។

## ៤. ថ្នាក់ទី១២ — មាត្រដ្ឋានត្រឹមត្រូវ

**ចុចអ្វី** បង្កើតថ្នាក់ថ្មី៖ កម្រិត **វិទ្យាល័យ** → **ថ្នាក់ទី១២** →
ជ្រើស **ក្រុមវិទ្យាសាស្ត្រ** → រួចបើក **ពិន្ទុ › បញ្ចូលពិន្ទុ**។

**គួរឃើញអ្វី**
- ពេលបង្កើតថ្នាក់ មានសំណួរ **ក្រុមសិក្សា** (វិទ្យាសាស្ត្រ / វិទ្យាសាស្ត្រសង្គម) —
  ហើយបង្កើតមិនបានទាល់តែជ្រើស
- ក្នុងទំព័របញ្ចូលពិន្ទុ មានស្លាក «មធ្យមសិក្សាទុតិយភូមិ · ថ្នាក់ទី១២ · ក្រុមវិទ្យាសាស្ត្រ»
- បញ្ជីមុខវិជ្ជាមាន **៦ មុខវិជ្ជា** (គណិតវិទ្យា, រូបវិទ្យា, គីមីវិទ្យា, ជីវវិទ្យា,
  ភាសាខ្មែរ, ប្រវត្តិវិទ្យា) — **មិនមែន** បញ្ជីបឋមសិក្សា
- ជ្រើស **គណិតវិទ្យា** → បង្ហាញ «ពិន្ទុពេញ ១២៥ · មេគុណ 2.5»
- បញ្ចូលពិន្ទុ ១២៥ បាន; បញ្ចូល ១៣០ មិនបាន

**បើមិនដូចនោះ** បើឃើញបញ្ជីបឋមសិក្សា (ស្តាប់/និយាយ/អាន/សរសេរ) — មានន័យថា
`00021` មិនទាន់អនុវត្ត ឬក្រុមសិក្សាមិនទាន់ជ្រើស។ ពិនិត្យសំណួរ verification
របស់ `00021`។

## ៥. ការប្រមូលពិន្ទុ

**ចុចអ្វី** ក្នុងថ្នាក់ណាមួយ → **ពិន្ទុ › ការប្រមូលពិន្ទុ**។

**គួរឃើញអ្វី**
- ទំព័របើកបាន និងបង្ហាញបញ្ជីមុខវិជ្ជាតាមស្ថានភាព (បានបញ្ចូលគ្រប់ / មិនទាន់គ្រប់ / មិនទាន់បញ្ចូល)
- មុខវិជ្ជាដែលមិនទាន់មានគ្រូ មានស្លាកក្រហម «មិនទាន់មានគ្រូ» និងសារព្រមានពីលើ
- មិនមានប៊ូតុងកែពិន្ទុនៅទំព័រនេះ (មើលបានតែប៉ុណ្ណោះ)

**បើមិនដូចនោះ** បើទំព័រមានបញ្ហា — ពិនិត្យថា `00024` បានអនុវត្តរួច។

## ៦. ប៊ូតុងសង្គ្រោះបញ្ជីសិស្ស — លេចឡើងតែកន្លែងដែលត្រូវ

> ធ្វើជំហាននេះ **បន្ទាប់ពី** បានរត់
> [`audit_recovery_safety.sql`](../supabase/audits/audit_recovery_safety.sql) រួច។

**ចុចអ្វី** បើក **បញ្ជីសិស្ស** សម្រាប់គណនីនីមួយៗដែល audit រាយក្នុងផ្នែកទី ៤
(ករណីសាមញ្ញ) និងផ្នែកទី ២ (ករណីមានស្ទួន)។

**គួរឃើញអ្វី**
- គណនីក្នុងផ្នែកទី ៤ → ប៊ូតុងសង្គ្រោះលេចឡើង ហើយ **សុវត្ថិភាពក្នុងការចុច**
- គណនីដែល audit មិនរាយឈ្មោះ → ប៊ូតុងមិនលេចឡើង

**បើមិនដូចនោះ — សំខាន់បំផុត**
បើប៊ូតុងលេចឡើងសម្រាប់គណនីក្នុង **ផ្នែកទី ២** (មានសិស្សស្ទួន) —
**កុំចុច និងកុំប្រាប់គ្រូឲ្យចុច**។ ការចុចនឹងធ្វើឲ្យសិស្សម្នាក់ក្លាយជាពីរនាក់
ក្នុងបញ្ជី។ គណនីទាំងនោះត្រូវការការបញ្ចូលគ្នា (merge) ជាមុនសិន
ដែលជាការងារដាច់ដោយឡែក មិនមែនប៊ូតុងនេះទេ។
